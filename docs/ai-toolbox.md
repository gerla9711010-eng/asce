## 跟我們有關的三件事

### 1. 找另一個 AI 來挑毛病

群裡出現最多次的共識。**我們已經在做**（文案交叉審核，08-06 上線）。

兩條原則值得留著：

- **AI 自己測自己等於沒測**。群裡的說法：「AI 會寫出 100% 會過的測試，但實際問題還在。」
  對照我們踩過的：守門員誤擋、KEIS 靜靜掉 18 筆，都是這個形狀。
- **第二個 AI 不能看到第一個的推理**，不然會被說服、變成點頭機器。
  → 我們的審核 prompt 第一句已經是「你不知道這篇文案是怎麼寫出來的，也不需要知道」，做對了。

**開發時的版本**：Claude 寫 → Codex 審。裝 `openai/codex-plugin-cc`（OpenAI 官方），
需要 ChatGPT 付費訂閱，Go 方案（$8/月）就含 Codex，官方標示「輕量編碼任務」、額度未公布。

### 2. 貴的模型只做決定，雜活丟便宜的

沒有人全程用最貴的模型。**我們已經在做**（產文案 `flash-lite`、審核 `flash`）。

還沒用的一招：**`/advisor opus`**（Claude Code 內建，零安裝，打一次存成預設）。
主模型維持 Sonnet，只有在「提交方案前／重複出錯／宣告完成前」才把 Opus 叫進來看完整對話。
適合動三條紅線、grab.py 雙向合併這種錯了很痛的操作。⚠️ 顧問 token 一樣計入訂閱額度。

**情報**：Claude 和 ChatGPT 這兩個月在打價格戰，很常無預警重置額度，額度沒想像中緊。

### 3. 政府開放資料變工具

群裡的實例：有人串**實價登錄**、有人做**垃圾車即時追蹤**、有人做**找廁所 App**（接環境部資料），
還有團隊 10 天把台灣一堆開放資料包成統一接口。

**對我們**：`kh-market` 行情看板現在資料要手動更新。這條路有人走通了，自動更新是做得到的。
