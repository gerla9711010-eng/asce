# sale-report — 屋主銷售報告書

## 何時使用

使用者給一個資料夾（例：`桌面\DM\銷報書\屏東\`）和物件地址，要一份**給屋主看**的銷售報告書。
交件＝PPT＋PDF 兩份，都複製到 `桌面\` 根目錄。

## 寫給屋主看 — 整份的語氣規則（每頁都適用）

1. **不要有任何「自白」**：不寫「資料不足」「待查」「推測」「我們無法確認」「僅供參考因為…」這類分析筆記。
   拿不到的資料就整格留空或整句拿掉，不要解釋為什麼空。
2. **不放抵押權、設定銀行、貸款金額**，任何一頁都不放（含第2頁表格與備註）。
3. 不放謄本裡跟賣價無關的雜項：防空避難室說明、車位要問管委會、「建議現場實勘」之類。
4. 用語要讓屋主聽得舒服：價格階梯第三列叫「理想成交」，不要叫「挑戰高標」（聽起來像貪心）；
   不要把「價格低」當成屋子的優點講給屋主聽。
5. 每個數字都要有出處（謄本／物件摘要／實登／開價列表／新聞／地圖座標），寫不出出處的不放。

## 前置：資料夾裡要有什麼

| 檔案 | 用途 | 沒有時 |
|---|---|---|
| 建物謄本 PDF（agent.foundi.info 電傳） | 第2頁、第9頁稅法 | 一定要有，缺就先問 |
| 物件摘要 PDF（樂屋／591 物件頁整理） | 第2頁**格局、車位、管理費**；第7頁周邊 | 謄本沒有格局，缺這份就問使用者格局 |
| 實價登錄 PDF（104woo 行情通，同巷/同社區） | 第3、4、6頁 | 一定要有 |
| 周遭開價：截圖 jpg/png **或** 貼上的列表文字 | 第5頁 | 貼文字 → 存成 `周遭開價.txt` 跑 `listings.py`（見 Step 5）|
| 土地謄本 PDF | 補土地持分 | 常常沒有 → 欄位留 `""`，稅法頁圓圈那行刪掉，不估不解釋 |

用 `pdfplumber` 讀 PDF。Windows 主控台是 cp950，**輸出一律先寫 utf-8 檔再 cat**（或 `PYTHONIOENCODING=utf-8`）。

## 主流程

### Step 1. 解析資料，先不要動版面

確認：**所有權登記日期與原因發生日**（決定稅制）、建物總面積／主建物／附屬建物／公設、
層次／總層數、**格局**（物件摘要）、車位型式、管理費。

本案**可能已經在市場上掛售**（首件屏東案在樂屋已掛 598 萬）。看到就跟使用者講一聲，
報告內容照常做；第5頁同社區在售的那幾戶照實列，不要去猜哪一戶是本案。

### Step 2. 挑對照組 — 用「同格局、坪數相近」，不是同樓層

1. **不要對全部筆數取平均。** 同社區單價常差 5 成以上，平均值是市場上不存在的數字。
2. 對照組 = **同格局（房數相同）且坪數相近**的成交；**1 樓排除**（有店面效用，單價天然高）。
   使用者明確否決過「同樓層」分組。
3. 對照組在 `deals.rows` 加 `"hl": true` → 第3頁紅字、第4頁深色長條。footnote 寫明分組規則。
4. 本案坪數在對照組裡偏大或偏小要講出來，那是價格定位往上或往下的直接理由。
5. 最新一筆成交距今超過 12 個月，第3頁 footnotes 寫明「近 N 個月無新成交紀錄」。

### Step 3. 排價格階梯 — 四列由低到高，彼此不打架

| 列 | 怎麼定 |
|---|---|
| 快速成交 | 對照組近期最低那幾筆 |
| 市場合理 | 對照組中位數附近 |
| 理想成交 | 對照組最高那幾筆 |
| 建議開價 | 理想成交＋議價空間，且落在（或貼近）周遭開價主流帶 |

寫完逐字核對三處是同一組數字：第6頁對照依據、bullets、結論帶「成交目標帶」。
第4頁右側 notes 的對照組統計（筆數、區間、中位數）也要跟第6頁一致。

### Step 4. 稅法頁按取得日期選稅制

- 取得日早於 105/1/1 → 舊制（房屋併綜所稅、土地只課土增稅），`box1_label` 改「房屋所得」。
- 105/1/1 之後 → 房地合一，依持有期間：≤2年 45%、2～5年 35%、5～10年 20%、>10年 15%；
  自住滿6年（本人/配偶/未成年子女設籍）獲利 400 萬內免稅、超過部分 10%。
- 成本價謄本查不到，不放不估。

### Step 5. 產檔 — 三支腳本照順序跑

```bash
SK=C:/Users/user/asce/.claude/skills/sale-report
cd <資料夾>
python $SK/listings.py <物件>.json   # 有貼開價文字才跑：產開價圖＋彙整PDF，回寫 listings 欄位
python $SK/build.py    <物件>.json   # 產 PPT
python $SK/export.py   <產出的.pptx> <PNG檢查資料夾>   # PNG 檢查圖＋PDF＋複製到桌面
```

JSON 從 `example.json` 複製改。欄位對應：`cover`→1、`subject`→2、`deals`→3＋4、`trend`→4、
`listings`→5、`price`→6、`life`→7、`flow`→8、`tax`→9；10～13 頁模板原樣。
表格內文字前面加 `!` 變紅字粗體。

**各頁規格（build.py 已經做好，改 JSON 就好）**

| 頁 | 規格 |
|---|---|
| 2 | 左表＝謄本＋格局＋車位；右側 notes 分段條列（社區/建築/樓層/格局/坪數/公設比/用途/車位/管理），不要一坨字 |
| 3 | 依時間**新到舊**；門牌寫「18號之2」，樓層獨立一欄；>10 列自動縮字 |
| 4 | 依時間**舊到新**；有縱軸「成交單價（萬元/坪）」與橫軸「成交年月／門牌樓層」標題 |
| 5 | 左圖右表。圖：坪數×開價散佈圖，同社區紅點、主流帶黃色；標籤 9.5pt，含社區名＋樓層＋開價＋單價＋刊登時間 |
| 6 | 價格階梯表＋bullets＋結論帶 |
| 7 | 見下方「第7頁怎麼寫」 |
| 9 | 三個標籤與文字自動對齊箭頭 |

**第5頁 listings.py 細節**
- 貼上的列表一筆一塊、以「大樓,住宅」這種類型行結尾；社區名、地坪可能缺，parser 已處理。
- 自動去重（總坪±0.2、主坪±0.15、樓層不矛盾、開價差≤10%）。跑完看 `_listings_check.txt`
  最下面「疑似同戶」，確定是同一戶就寫進 `listings.src.groups`（原始編號）再跑一次。
- 刊登時間：平台只有「N天前更新」，以同戶各平台最早一筆推算＝**最少**刊登時間。
  **未滿 2 個月不標**（使用者決定，標「17天」反而誤導）；滿 9 個月的戶數會進右側 notes。
- 標籤自動排左右兩欄；真的要微調用 `listings.src.labels: {"原始編號": [x, y]}`。

**第7頁怎麼寫（生活圈範圍）**
- 照原稿模板的寫法：三個**有名字的區域**（××商圈／××生活圈／××園區），各一段 40～60 字，
  寫地標＋距離＋這個區域給生活帶來什麼。語氣是專業房仲對屋主介紹，也是之後對買方的賣點。
- **不寫**：價格低、公車站幾公尺、有電梯、有管理員——每個社區都有，不是賣點。
- 距離用 `geo.py` 查 OpenStreetMap 座標算直線距離，一律寫「約 X 公尺／公里」，座標記在
  `life._distances` 備查。查不到的地標（例：屏東科學園區會回北京）改查附近車站並在文案寫明
  「（六塊厝）」。學區沒有官方公告就只寫學校距離，不寫「學區」。
- 未來題材（科學園區、捷運、高鐵）只寫已發生的事實＋官方預估數字＋新聞出處，不寫「房價將上漲」。
  太遠的（高鐵 2039）不放。
- 圓圈標籤 ≤5 字（`circle_runs` 兩段），超過會斷行。`texts` 可以是字串或多行 list；
  `life.title` 可覆蓋頁標題。

### Step 6. 逐頁看過再交件

`export.py` 會出 1400×788 的 PNG 到檢查資料夾，**每頁都要真的打開看**（字擠爆格子、標籤重疊在
XML 看不出來）。PDF 是 2400×1350 圖片合成（PowerPoint 2007 不能 SaveAs PDF；Pillow 缺 JPEG 外掛
不能存 PDF，用 reportlab）。複製到桌面失敗＝使用者開著那份檔，請他關掉再跑 export.py。

## 已知的坑

1. **不要 `add_slide()` 或重排頁序。** 標題旗標、裝飾是 slide 層級 shape，空白 layout 是全白頁。
2. **模板字體多數電腦沒裝**（Source Han Sans TC、Gungsuh、思源黑体），缺字會整段空白（例：「厝」）。
   `build.py` 最後 `force_font()` 把 13 頁全部改微軟正黑體——副作用是封面與標籤不再是書法字，這是刻意的。
3. **圖表資料標籤要另外設 chart-space 字體**（`set_font_name(ch.font, ...)`），PowerPoint 忽略 dLbls 的 txPr。
4. **第9頁箭頭在縮放過的群組裡**，raw 座標跟畫面差 0.3"；build.py 用的是畫面實測位置，換模板要重量。
5. **五層公寓不要寫「有電梯」。** 謄本附屬建物常載「電梯樓梯間」，那是登記用語。

## 法規check（每次動手前對一遍）

- 個資法：所有權人姓名、統編、地址、**抵押權人與金額**不進簡報。產出只留本機，不上傳、不發連結。
- 平均地權條例47-3：實登門牌帶「之號＋樓層」是銷報書慣例，但可識別個別交易。要更保守就把之號遮成
  `18號之X`——先問使用者，不要自己決定。
