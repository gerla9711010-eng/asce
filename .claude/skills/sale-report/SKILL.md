# sale-report — 屋主銷售報告書

## 何時使用

使用者給一個資料夾（通常是 `桌面\送件\`）和一個物件地址，要一份給屋主看的銷售報告書 PPT。

## 前置：資料夾裡要有什麼

| 檔案 | 用途 | 沒有時 |
|---|---|---|
| 建物謄本 PDF（agent.foundi.info 電傳） | 第2頁本案現況、第9頁稅法 | 一定要有，缺就先問 |
| 實價登錄 PDF（104woo 行情通，同巷/同社區） | 第3頁表、第4頁圖、第6頁定價依據 | 一定要有 |
| 周遭開價截圖 jpg/png | 第5頁 | 可省略，但第5頁會空掉，要先問 |
| 土地謄本 PDF | 補土地持分 | 常常沒有 → 一律標「待查」，**不要估**  |

用 `pdfplumber` 讀 PDF（`extract_text` + `extract_tables`）。Windows 主控台是 cp950，**輸出一律先寫 utf-8 檔再 cat**，直接 print 中文會 UnicodeEncodeError。

## 主流程

### Step 1. 解析資料，先不要動版面

把謄本與實登抽成純文字看過一遍。特別確認：**所有權登記日期**（決定稅制）、**建物總面積／主建物／附屬建物**、**層次／總層數**、**抵押權設定金額**。

### Step 2. 挑對照組 — 這步決定整份報告可不可信

1. **不要對 10 筆取平均。** 同巷同屋型的單價常常差 5 成以上（首件是 @8.0～@25.0），平均值會給屋主一個市場上不存在的數字。
2. 主要對照組 = **同樓層**的成交。頂樓對頂樓、1 樓單獨看（1 樓有店面效用，單價天然高，不能混進住家對照）。
3. 對照組在第3頁表格用 `"hl": true` 標紅字，第4頁圖表會自動變深色。
4. 本案坪數在對照組裡偏大或偏小要講出來，那是價格定位往上或往下的直接理由。
5. **最新一筆成交距今超過 12 個月，就要在第3頁 footnotes 寫明「近 N 個月無新成交紀錄」。**

### Step 3. 排價格階梯 — 四列必須由低到高，彼此不打架

| 列 | 怎麼定 |
|---|---|
| 快速成交 | 同樓層近期最低那筆 |
| 市場合理 | 同樓層中段 + 全部筆數中位數 |
| 挑戰高標 | 同樓層最高那筆 |
| 建議開價 | 挑戰高標 + 議價空間，且要落在周遭開價主流帶內 |

寫完**逐字檢查三個地方講的是不是同一組數字**：bullets 裡的「成交多落在 X」、bullets 裡的「收斂至 Y」、結論帶的「成交目標帶 Z」。首件就是這裡先寫出互相矛盾的三個區間，屋主只會記得這個數字，錯了最傷。

成交目標帶不可以高過你自己在 bullets 裡叫屋主「不要對標」的那一筆。

### Step 4. 稅法頁按取得日期選稅制 — 不要照抄模板

模板第9頁寫的是房地合一。**取得日早於 105/1/1 就不適用**，要改成舊制財產交易所得（房屋併入綜所稅、土地只課土增稅），`box1_label` 跟著改成「房屋所得」。取得日在 105/1/1 之後才保留房地合一 ×20%。重購退稅與一生一次兩塊不受影響。

成本價（當年買價）謄本查不到，**不要放、不要估**。

### Step 5. 產檔

複製 `example.json` 改欄位，然後：

```bash
python C:/Users/user/asce/.claude/skills/sale-report/build.py <你的>.json
```

預設輸出 `桌面\DM\銷報書\<out_name>\<out_name>_銷售報告書.pptx`。JSON 欄位對應：`cover`→1、`subject`→2、`deals`→3＋4、`trend`→4、`listings`→5、`price`→6、`life`→7、`flow`→8、`tax`→9；10～13 頁（專約、團隊、商辦、門市）模板原樣不動。表格內文字前面加 `!` 會變紅字粗體。

### Step 6. 逐頁看過再交件

本機沒有 LibreOffice，用 PowerPoint COM 出圖：

```powershell
$app = New-Object -ComObject PowerPoint.Application
$pres = $app.Presentations.Open($f, $true, $false, $false)
$pres.Export($out, "PNG", 1400, 788)
$pres.Close(); $app.Quit()
Get-Process POWERPNT -ErrorAction SilentlyContinue | ForEach-Object { $_.Kill() }
```

PowerPoint 是 2007，`SaveAs(path, 32)` 轉 PDF 會 `RPC_E_SERVERFAULT`，只能出 PNG，不要浪費時間試。中文字擠爆格子在 XML 裡看不出來，**一定要真的把圖看過**。

最後複製一份到 `桌面\` 根目錄，使用者習慣從那裡開。

## 已知的坑

1. **不要 `add_slide()` 或重排頁序。** 標題旗標、裝飾圖形都是 slide 層級 shape，空白 layout 產出來是全白頁。13 頁的角色固定，只換內容。
2. **中文字體會變毛筆字。** `run.font.name` 只寫 `<a:latin>`，中文掉回模板主題的書法字體。要用 `helpers.set_font_name()` 補 `<a:ea>`／`<a:cs>`。
3. **圖表資料標籤要另外設 chart-space 字體**（`set_font_name(ch.font, ...)`），PowerPoint 會忽略 dLbls 自己的 txPr。
4. **毛筆標題字體缺字。** 「厝」就沒有，會靜靜留白不報錯。第7頁標題避開冷僻字（首件把「三塊厝商圈」改成「建國商圈」，內文才寫三塊厝車站——內文是微軟正黑體沒問題）。
5. **五層公寓不要寫「有電梯」。** 謄本附屬建物常載「電梯樓梯間」，那是登記用語。照抄謄本原文並註明，不要自己推論。

## 法規check（每次動手前對一遍）

- 個資法：謄本上所有權人姓名、統編、地址**不要進簡報**。產出只留本機，不要上傳任何連結。
- 平均地權條例47-3：實登門牌帶「之號＋樓層」是銷報書慣例，但屬於可識別個別交易。要更保守就把之號遮成 `458巷3-X號`——先問使用者，不要自己決定。
